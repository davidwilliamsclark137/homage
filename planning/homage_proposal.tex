\section{Current Focus}
\label{sec:org2e0d8ab}

\subsection{Phone app}
\label{sec:org8f5f7aa}

\begin{itemize}
\item Document Studio should be the primary active experience.
\item Desktop/web preview is useful for development but not the product focus right now.
\item Sky, music, and quest studio work is parked for later.
\end{itemize}
\subsection{Local-first direction}
\label{sec:org86b7367}

\begin{itemize}
\item SQLite remains the canonical metadata and event store.
\item Large generated assets can remain file-backed: PDFs, \LaTeX{}, uploads, audio, and exported artifacts.
\item Backend APIs should support local-first sync and publishing without making the app feel server-dependent.
\end{itemize}
\section{Working Questions}
\label{sec:orgb408aeb}

\subsection{Product}
\label{sec:org784b880}

\begin{itemize}
\item Who is the first real user of Document Studio?
\item What document should someone be able to make in under five minutes?
\item What should feel magical on a phone instead of merely possible?
\item What should be saved locally even when network access is unavailable?
\end{itemize}
\subsection{Writing flow}
\label{sec:org0d5a3e7}

\begin{itemize}
\item What are the minimum fields needed to publish a useful document?
\item Should the app begin with a blank page, a guided prompt, or a reusable template?
\item How much \LaTeX{} control should be exposed to the user?
\item What does "finished" mean: PDF, artifact, local library entry, shared drop, or all of these?
\end{itemize}
\subsection{Technical}
\label{sec:orgee1fb43}

\begin{itemize}
\item Which document metadata belongs in SQLite?
\item Which generated files belong on disk?
\item What should the backend generate versus what the client can preview locally?
\item What needs to work when the phone is remote over an Expo tunnel?
\end{itemize}
\section{Proposed Milestones}
\label{sec:org3a882f8}

\subsection{{\bfseries\sffamily TODO} Milestone 1: Clarify the core document loop}
\label{sec:orgd6d9d7f}

\begin{itemize}
\item Open Document Studio on phone.
\item Draft a document.
\item Preview the design.
\item Publish/generate a PDF.
\item Save the result locally as an artifact.
\end{itemize}
\subsection{{\bfseries\sffamily TODO} Milestone 2: Make the document library useful}
\label{sec:org41ad217}

\begin{itemize}
\item Browse previously generated documents.
\item Reopen PDFs.
\item Show saved source metadata.
\item Make failures legible when backend or file access is unavailable.
\end{itemize}
\subsection{{\bfseries\sffamily TODO} Milestone 3: Improve templates}
\label{sec:orgd6b5d76}

\begin{itemize}
\item Define a small set of opinionated document styles.
\item Decide whether templates are code-defined, database-defined, or file-defined.
\item Add one template that feels specific to Homage rather than generic.
\end{itemize}
